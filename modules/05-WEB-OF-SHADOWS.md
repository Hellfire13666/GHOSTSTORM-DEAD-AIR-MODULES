## ☣️ WHAT THIS SPECIAL MODULE DOES

A source-aware visual relationship map for linking research topics and related publicly observed records. The aim is to make evidence provenance legible, not to infer real-world identity from a single matching name or domain.

## 🎛️ RESEARCH INPUTS

Public entities, events, domain references and records that a researcher explicitly selects.

## 🌈 WHAT YOU SEE

A connected diagram showing documented source-to-record relationships, with labels, citations and uncertainty visible.

## ⚡ EXAMPLE // EXPERIENCE THE WORKFLOW

**Illustrative interface example, not an executable command:** Draw Public Domain → Certificate Record → Historical Snapshot, attaching a source citation to each edge; clicking a link shows which public observation supports it.

**Example status:** Design/workflow demonstration, not proof of a currently deployed visualization engine or working endpoint.
