## 🔎 EXPLORE THE SPECIAL BUILDS

**🌈 01 // [HEXCODEX // GUEST TERMINAL](modules/01-HEXCODEX.md)**

The public-facing beginner doorway for GHOSTSTORM GEO TERMINAL: a self-contained GitHub Pages guide with a one-paste installer, 20 copy-ready recipes, colorful public-source output and the one-word `ghoststorm` launcher.

**🌍 02 // [GHOST MAP // GEO SIGNALS](modules/02-GHOST-MAP.md)**

The geography and location-facing module family. Organizes public OpenStreetMap place data, geographic event references and readable geographic context. Historical development involved Earthwraith, public-history lookups and route adapters.

**🕸️ 03 // [SEVEN GUEST BAYS // PUBLIC-SOURCE ARCADE](modules/03-SEVEN-GUEST-BAYS.md)**

Seven related research workspaces: City Hunter, Grave Registry, Storm Chaser, Phantom Seal, Deadlink Echo, Earthwraith and Void Routes. These are a **single group** for cataloging, not seven new repositories.

**📡 04 // [PHANTOM PULSE // SIGNAL RHYTHM](modules/04-PHANTOM-PULSE.md)**

A research interface concept in the approved GHOSTSTORM family for interpreting time-based public signals, source updates, and changing observations without hiding timestamps or source errors.

**🕷️ 05 // [WEB OF SHADOWS // RELATIONSHIP ATLAS](modules/05-WEB-OF-SHADOWS.md)**

A source-aware visual relationship map for linking research topics and related publicly observed records. The aim is to make evidence provenance legible, not to infer real-world identity from a single matching name or domain.

**💾 06 // [GHOST HARVEST // RESEARCH RECEIPTS](modules/06-GHOST-HARVEST.md)**

A public-source collection and evidence-context workflow in the GHOSTSTORM family. It emphasizes keeping original titles, URLs, observation dates, timestamps, source names, provider errors and data limitations with any saved research.
